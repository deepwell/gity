# Security Policy

## Supported Versions

Security fixes are made on `main` and shipped in the next release. Only the
latest release (as published on [Flathub](https://flathub.org/apps/details/com.markdeepwell.GitY))
is supported.

## Reporting a Vulnerability

Please do not open a public issue for security problems.

Email **mark@markdeepwell.com** with a description of the issue, the GitY
version (or commit), and steps to reproduce. A minimal repository that
triggers the problem is especially helpful.

You can expect an acknowledgement within 7 days. Once a fix is available it
will be released and the reporter credited, unless they prefer otherwise.
